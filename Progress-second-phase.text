	QLever versions

To download and compile QLever see ....
Download to /home/local/qlever/qlever-code-<date>
The current version of QLever code is in /home/local/qlever/qlever-code, which is a symbolic link to one of the dated versions.
To switch between versions change the symbolic link.


	QLever indexes and benchmarks

Creating an index
  QLever
    Edit /home/local/scripts/QLever-load to load the correct files
    Run /home/local/scripts/QLever-load

Setting up for benchmarks
  Create the appropriate index, if necessary
  Edit <engine>-run so that it uses the index, if necessary
    QLever-run has an argument for this

Runing benchmarks
  .../queries/run-ontology <engine> <version> [<directory>]
  .../queries/run-existing <engine> <version> [<directory>]
  .../queries/run-scholia <engine> <version> [<directory>]
